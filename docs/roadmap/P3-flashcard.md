# P3: フラッシュカード（単語カード）

> 表＝言葉、裏＝意味/例文。タップで裏返し、左右スワイプで「覚えてる/覚えてない」を記録。

> **注記（2026-07）**: 実装時の決定を本文にも反映済み — 評価は**単語単位**に統一し（カード1枚＝単語1件・裏面に全ての意味を並列表示）、意味単位のスワイプは行わない。スワイプは **右=知っている / 左=まだ学習中 / 上=単語を編集** の3方向で、反転は**タップ**が担う（上スワイプを編集に割り当てたため）。`scope` は新名称を増やさず P0 の `StudyScopeSchema`（`all|unmastered`）を再利用する。UI は Figma プロトタイプの挙動仕様に合わせた（下記「ジェスチャ・アニメーションの確定値」）。出題方向トグル・発音再生（Google Cloud TTS）・結果画面は計画外の追加実装。

- **依存**: P0（review API・対象抽出）
- **領域**: `server` / `webfront`
- **完了でアンロックされるもの**: P4, P6

## 目的

- 各セットの言葉をカードで学習（要件定義「単語カードのビュー」）。
- 表は言葉のみ（＋発音記号・品詞）、タップで裏返し意味/例文/写真。
- スワイプで状態更新・遷移（表裏どちらでも同じ操作が使える）:
  - **右スワイプ**: 知っている。単語全体（全 meaning）が `isRemembered=true` になる。
  - **左スワイプ**: まだ学習中。単語全体が `isRemembered=false` になる。
  - **上スワイプ**: 単語を編集する（評価は付かず、同じカードに留まる）。
- 出題方向を切り替えられる（`語句 → 意味` / `意味 → 語句`）。表示上の切り替えで、APIには送らない。

## スコープ

### やる
- カードデッキ生成 API（対象: 全て / 未習得）。
- スワイプ結果記録 API（`review` を `mode='flashcard'`、`result`=`known`/`unknown`）。
- `word_meaning.isRemembered` の更新（単語単位で全 meaning に適用）、および全 meaning が `isRemembered=true` → `word.isMastered=true` の導出更新。
- Web: カードUI（タップで裏返し・左右スワイプで評価・上スワイプで編集）。

### やらない
- 出題順の忘却曲線最適化（P4。P3 では対象フィルタまで）。
- モバイルのカードUI（P6）。

## データモデル差分

- P0 の `review_log` / `review_state` を利用。
- 既存 `word_meaning.isRemembered` / `word.isMastered` を更新（スキーマ変更なし）。

## API 仕様

| Method | Path | 概要 |
|---|---|---|
| GET | `/cards/:setId?scope=all\|unmastered&limit=N` | カードデッキ（言葉＋全ての意味＋画像キー）を1往復で返す |
| POST | `/cards/:setId/swipe` | スワイプ記録。body: `{ wordId, remembered }`。評価は単語単位（配下の全 meaning に適用） |

- `swipe` は1トランザクションで、配下の各 meaning に `review_log`（`mode='flashcard'`）を記録し
  `review_state` を更新（`study.saveReviewInTx` を共有）、`isRemembered` を一括更新したうえで
  `isMastered` を再計算する（`study.recalcMasteredInTx` をクイズと共有）。
- `scope` は P0 の `StudyScopeSchema`（`all|unmastered`）を再利用する。評価が単語単位のため、
  絞り込みも単語粒度（`word.isMastered`）が正しい基準になる。UI表記は「未習得」。

## 主要UI / 画面

- カード開始（範囲: すべて / 未習得、発音の自動再生トグル）。
- カード（表=白 / 裏=黒。品詞＋テキスト＋「タップして裏返す」＋音量ボタン）。
  補助情報（発音記号・例文・写真・場所）はカードに載せず、編集画面で見る。
- ヘッダー（閉じる＋出題方向トグル）、上部の進捗バー、下部のカウンター
  （左=まだ学習中の枚数 / 中央 `n / total` / 右=知っているの枚数）。
- 長文の面は下端をカード色へフェードさせ「もっと見る」を出す。タップで全文のボトムシート
  （共通の `BottomSheet`。つまみのドラッグと下スワイプで閉じる）。
- 完了画面（✓ / 「完了しました！」/ N枚学習・覚えた N枚 / もう一度）。

## ジェスチャ・アニメーションの確定値（Figma プロトタイプ準拠）

意図なく変えないこと。

| 項目 | 値 |
|---|---|
| 判定順序 | 上（編集）→ 右 → 左。斜め上でも上方向が閾値を超えれば編集が優先される |
| 横の確定閾値 | `|x| > 100px`（速度判定はしない・カード幅比でもない） |
| 上の確定閾値 | `y < -200px` |
| ドラッグ | `dragConstraints` 全て0 ＋ `dragElastic 0.7` |
| 傾き | `x: -200→+200px` で `-15deg→+15deg`（線形） |
| 本文の消失 | 縦横いずれか `10px` 超で `opacity: 0` |
| 左右ラベルの濃さ | `min(0.8, |x| / 100 * 0.8)`。`y < -150px` の間は非表示 |
| 編集ラベルの濃さ | `y: -150→-200→-300px` で `0→0.3→0.8`。左右より前面（z-20） |
| 色 | 左=オレンジ / 右=エメラルド / 上=ブルー（`bg-*/5` ＋ `border-4` ＋ `text-*-600`） |
| 反転 | タップのみ。3D Y軸回転 `spring(stiffness 260 / damping 20 / duration 0.6)`、両面 `backface-visibility: hidden` |
| 入場 | `scale 0.9→1` / `opacity 0→1`、`spring(300 / 30)` |
| 退出 | スワイプ方向へは飛ばさず `scale 0.9` ＋フェード（0.2s） |
| 進捗 | 左右スワイプ確定時のみ加算（反転・編集・音声切替では進まない） |

## 発音（Google Cloud TTS）

- 出題方向に応じて言語を切り替える。`語句 → 意味` は 表=en / 裏=ja、`意味 → 語句` は逆。
- 自動再生は表＝カード表示から 300ms 遅延、裏＝反転した瞬間。
- ON/OFF は**表裏共通の1つの状態**（localStorage `flashcard-audio`）。開始画面のスイッチと
  カード上の音量ボタンのどちらからでも切り替わる。OFFで即停止、ONで今見ている面を読み上げる。
